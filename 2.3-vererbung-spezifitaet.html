1 — CSS-Selektoren: Übersicht

ℹ

Diese Lektion vertieft Selektoren, Vererbung und Spezifität. Für die folgenden Lektionen reichen die Grundlagen aus Lektion 2.1 – du kannst die Theorie also auch später durcharbeiten, etwa wenn eine Regel „nicht greift“. CSS-Selektoren bestimmen, welche HTML-Elemente von CSS-Regeln betroffen sind. In Lektion 2.1 haben wir die häufigsten kennengelernt – hier kommt der vollständige Überblick.

KategorieBeispiele

2 — Element- und Klassen-Selektoren

Element-Selektoren

  • Wählen alle Elemente eines bestimmten Typs aus
  • Niedrigste Spezifität

Klassen-Selektoren

  • Wiederverwendbare Styles für mehrere Elemente
  • Mit . (Punkt) eingeleitet
HTML HTML 
<p>Normaler Text</p>
<p class="wichtig">Wichtiger Text</p>
<p class="wichtig hervorgehoben">Sehr wichtig</p>
CSS CSS 
p { color: black; }                    /* Alle Paragraphen */
.wichtig { color: red; }               /* Klasse wichtig */
.hervorgehoben { font-weight: bold; }  /* Klasse hervorgehoben */

Mehrere Klassen

Ein Element kann beliebig viele Klassen haben – durch Leerzeichen getrennt (class="wichtig hervorgehoben"). Es bekommt dann die Styles aller Klassen.

3 — ID- und Attribut-Selektoren

ID-Selektoren

  • Eindeutige Identifikation eines Elements
  • Mit # (Raute/Hash) eingeleitet
  • Höchste Spezifität aller Selektoren

Attribut-Selektoren

  • Wählen Elemente anhand ihrer Attribute aus
  • Vielseitige Matching-Möglichkeiten
HTML HTML 
<div id="header">Kopfbereich</div>
<input type="email" required>
<a href="mailto:test@example.com">Email</a>
CSS CSS 
#header { background: blue; }           /* ID-Selektor */
[required] { border: 2px solid red; }   /* Hat ein required-Attribut */
[href^="mailto:"] { color: green; }     /* href beginnt mit mailto: */
Attribut-SelektorTrifft Elemente, deren Attribut …
[attr]… vorhanden ist
[attr="wert"]… genau wert ist
[attr^="wert"]… mit wert beginnt
[attr$="wert"]… mit wert endet
[attr*="wert"]… wert irgendwo enthält

4 — Pseudo-Selektoren und Kombinatoren

Pseudo-Klassen (mit :)

  • Wählen Elemente in bestimmten Zuständen
  • :hover, :focus, :first-child, :nth-child()

Pseudo-Elemente (mit ::)

  • Wählen Teile von Elementen
  • ::before, ::after, ::first-line
Pseudo-Klassen und -Elemente CSS 
a:hover { color: red; }                       /* Hover-Zustand */
li:first-child { font-weight: bold; }         /* Erstes li-Element */
p::first-line { text-transform: uppercase; }  /* Erste Zeile */

Kombinatoren

Kombinatoren CSS 
/* Nachfahre */        .menu a { color: blue; }
/* Direktes Kind */    .menu > a { color: red; }
/* Nachfolger */       h1 + p { margin-top: 0; }
/* Geschwister */      h1 ~ p { color: gray; }
KombinatorBedeutung
.menu aalle <a> irgendwo innerhalb von .menu (auch tief verschachtelt)
.menu > anur <a>, die direkte Kinder von .menu sind
h1 + pdas <p>, das unmittelbar nach einem <h1> folgt
h1 ~ palle <p>, die nach einem <h1> auf derselben Ebene folgen

5 — CSS Inheritance (Vererbung)

Bestimmte CSS-Eigenschaften werden automatisch vom Eltern- an die Kindelemente weitergegeben. Setzt man z. B. color auf <body>, wird sämtlicher Text auf der Seite in dieser Farbe dargestellt.

Vererbbare Eigenschaften

  • Text: color, font-family, font-size, line-height
  • Listen: list-style-type
  • Tabellen: border-collapse

Nicht vererbbar

  • Layout: width, height, margin, padding
  • Hintergrund & Rahmen: background-color, border

Steuerung

inheritExplizit vom Eltern-Element erben – auch bei nicht vererbbaren Properties
initialAuf den Standardwert der Property (laut Spezifikation) zurücksetzen
unsetVerhält sich wie inherit bei vererbbaren Properties und wie initial bei allen anderen
💡
Faustregel

Alles, was mit Text zu tun hat, wird vererbt. Alles, was mit der Box zu tun hat (Größe, Abstände, Rahmen, Hintergrund), nicht.

6 — Inheritance-Beispiele

HTML-Struktur HTML 
<body>
  <div class="container">
    <p>Dieser Text ist blau (geerbt)</p>
    <p class="special">Spezieller Text</p>
    <span>Span-Text</span>
  </div>
</body>
CSS CSS 
body {
  color: blue;      /* Vererbt sich */
  margin: 20px;     /* Vererbt sich NICHT */
}

.container {
  border: 1px solid black; /* Vererbt sich NICHT */
}

.special {
  color: inherit;   /* Explizit erben: wird blau */
  margin: inherit;  /* Explizit erben: wird 20px */
}

Ergebnis: Alle Texte sind blau, aber nur .special hat einen Margin von 20px.

7 — CSS-Spezifität

Die Spezifität bestimmt, welche CSS-Regel angewendet wird, wenn mehrere Regeln auf dasselbe Element zutreffen und sich widersprechen.

Spezifitäts-Berechnung

#ArtPunkteBeispiel
1Inline-Styles1000style="..."
2IDs100#id
3Klassen, Attribute, Pseudo-Klassen10.class, [attr], :hover
4Elemente, Pseudo-Elemente1div, ::before
ℹ
Faustregel
Inline > IDs > Klassen > Elemente
Bei gleicher Spezifität gewinnt die später definierte Regel!
⚠
Punkte sind kein echtes Zehnersystem

Die Schreibweise 0-1-2-1 ist genauer als eine Summe: Jede Stelle ist eine eigene Kategorie. Auch 11 Klassen (11 × 10 = 110 „Punkte“) schlagen keine einzige ID – zuerst wird die ID-Stelle verglichen, erst bei Gleichstand die Klassen-Stelle.

8 — Spezifität: Beispiele

HTML HTML 
<p id="wichtig" class="text highlight">Welche Farbe hat dieser Text?</p>
CSS-Regeln und ihre Spezifität CSS 
p { color: black; }                    /* 0-0-0-1 = 1 */
.text { color: blue; }                 /* 0-0-1-0 = 10 */
.highlight { color: yellow; }          /* 0-0-1-0 = 10 */
#wichtig { color: red; }               /* 0-1-0-0 = 100 */
p.text.highlight { color: green; }     /* 0-0-2-1 = 21 */
#wichtig.highlight { color: purple; }  /* 0-1-1-0 = 110 */

Ergebnis: Der Text ist purple (höchste Spezifität: 110).

Bei Gleichstand

Gleiche Spezifität CSS 
.text { color: blue; }         /* Spezifität: 10 */
.highlight { color: yellow; }  /* Spezifität: 10, aber später → gewinnt! */

9 — Der CSS-Cascading-Algorithmus

Das „C“ in CSS steht für Cascading. Der Cascading-Algorithmus bestimmt in folgender Reihenfolge, welcher Wert angewendet wird:

  1. Origin und Importance
    • Browser-Standard < Benutzer < Autor
    • !important kehrt die Reihenfolge um
  2. Spezifität
    • Inline (1000) > ID (100) > Klasse (10) > Element (1)
  3. Source Order (Reihenfolge)
    • Bei gleicher Spezifität: später definiert gewinnt
  4. Inheritance
    • Gibt es gar keine Regel für das Element, werden vererbbare Eigenschaften vom Eltern-Element übernommen

Beispiel des kompletten Prozesses

Cascade CSS 
/* 1. Browser-Standard: color: black */
/* 2. Autor-CSS: */ p { color: blue; }        /* Spez: 1 */
/* 3. Autor-CSS: */ .text { color: red; }     /* Spez: 10 → gewinnt */
/* 4. Autor-CSS: */ .other { color: green; }  /* Spez: 10, aber früher */
/* 5. HTML: */     style="color: yellow"      /* Spez: 1000 → gewinnt */

Ohne Inline-Style wäre der Text rot (.text schlägt p). Mit dem Inline-Style in Zeile 5 gewinnt am Ende gelb.

10 — Praktische Tipps

Best Practices für CSS-Selektoren

✓ DO

  • Verwende Klassen für wiederverwendbare Styles
  • Halte Selektoren so einfach wie möglich
  • Nutze semantische Klassennamen
  • Strukturiere CSS logisch (generell → spezifisch)

✗ DON’T

  • Vermeide zu spezifische Selektoren: .menu ul li a
  • Verwende IDs nicht fürs Styling (nur für JavaScript und Sprungmarken)
  • Vermeide !important (außer in Ausnahmefällen)
  • Nutze keine Inline-Styles fürs Design
Gut vs. schlecht CSS 
/* Gut */
.navigation-link { color: blue; }
.navigation-link:hover { color: red; }

/* Schlecht */
#header nav ul li a { color: blue !important; }
💡
Debugging-Tipp

Die Browser-Entwicklertools zeigen im Tab Styles alle angewendeten Regeln – überschriebene Deklarationen sind durchgestrichen. Fährst du mit der Maus über einen Selektor, zeigt Chrome dessen Spezifität an.

📁 Stand nach dieser Lektion: beispiele/2.3/

Häufige Fehler

Fehler: Regel wird „ignoriert“

.rot { color: red; } wirkt nicht, weil weiter oben #inhalt p { color: black; } steht.

Spezifität vergleichen (0-1-0-1 schlägt 0-0-1-0). Die ID aus dem Selektor entfernen, statt mit !important nachzulegen.

Fehler: Erwarten, dass margin oder border vererbt wird

Ein Rahmen auf dem Container erscheint nicht bei den Kindern.

Box-Eigenschaften werden nicht vererbt. Bei Bedarf die Kinder direkt selektieren oder inherit verwenden.

Fehler: !important-Spirale

Eine Regel wird mit !important erzwungen, die nächste Änderung braucht wieder !important …

Selektoren flach halten (eine Klasse) und Regeln in der Reihenfolge allgemein → spezifisch anordnen.

Aufgaben

Aufgabe 1 Spezifität berechnen

Berechne die Spezifität (Schreibweise 0-0-0-0) und ordne nach Stärke:

  • nav ul li a
  • .hauptnav__link:hover
  • #main-header .light
  • a[href^="mailto:"]
  • article p::first-line
Aufgabe 2 Welche Farbe?

Ein <li class="aktiv"> steht in <ul id="menu">. Es gelten #menu li { color: gray; }, .aktiv { color: green; } und li { color: black !important; }. Welche Farbe hat der Text – und warum?

Aufgabe 3 Kombinatoren auf der Demoseite

Formatiere auf der Demoseite den ersten Absatz direkt nach jeder <h2> kursiv (h2 + p) und den ersten Meilenstein im Lernprojekt fett (li:first-child).

Bonus Formular per Attribut-Selektor

Hebe im Einreichen-Formular alle Pflichtfelder ([required]) mit einem linken Rahmen hervor. Kennzeichne außerdem alle externen Links (a[href^="http"]) mit einem nachgestellten „↗“ per ::after.
