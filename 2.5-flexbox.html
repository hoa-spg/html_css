Lektion 2.5 — Teil 2: CSS & Layout

Flexbox: Container & Kinder

Flexbox ca. 120 min Layout

Lernziele

  • Die Idee hinter dem Flexbox Layout Module erklären und Main-Axis und Cross-Axis unterscheiden
  • Einen Flex-Container erstellen und Richtung und Umbruch mit flex-direction und flex-wrap steuern
  • Flex-Kinder mit justify-content, align-items und align-content ausrichten und Abstände mit gap setzen
  • Die Reihenfolge von Flex-Kindern mit order ändern
  • Wachsen, Schrumpfen und Wunschgröße mit flex-grow, flex-shrink und flex-basis steuern und die Kurzschreibweise flex lesen
  • Ein mehrzeiliges Mobile-First-Layout mit Flexbox umsetzen

1 — Flexbox Layout Module

Das Flexbox-Layout-Modul soll eine effizientere Methode bieten, um Elemente in einem Container anzuordnen, auszurichten und den Platz zwischen ihnen zu verteilen – selbst wenn ihre Größe unbekannt und/oder dynamisch ist (daher das Wort „Flex“).

Die Hauptidee: Der Container bekommt die Möglichkeit, die Breite/Höhe (und die Reihenfolge) seiner Elemente zu verändern, um den verfügbaren Platz bestmöglich auszufüllen – hauptsächlich, um sich an alle Arten von Anzeigegeräten und Bildschirmgrößen anzupassen.

ℹ
Container und Kinder

Flexbox arbeitet immer mit zwei Ebenen: dem Flex-Container (Eltern-Element) und den Flex-Kindern (Flex-Items, seine direkten Kinder). Diese Lektion behandelt zuerst die Properties des Containers, danach die der Kinder.

2 — Main-Axis und Cross-Axis

Die MAIN-AXIS (Hauptachse) eines Flex-Containers ist die primäre Achse, entlang der die Flex-Elemente angeordnet werden. Sie muss nicht unbedingt horizontal sein – das hängt von der Property flex-direction ab.

Die CROSS-AXIS (Querachse) steht senkrecht zur Hauptachse. Ihre Richtung hängt daher von der Richtung der Hauptachse ab.

💡
Merkhilfe

Alles mit justify wirkt auf der Main-Axis, alles mit align auf der Cross-Axis.

3 — Flex-Container: display & flex-direction

display CSS 
div {
  display: flex | inline-flex;
}

Definiert einen Flex-Container – als Block (flex) oder inline (inline-flex). Er aktiviert einen Flex-Kontext für alle seine direkten Kinder.

flex-direction

flex-direction CSS 
div {
  flex-direction: row | row-reverse |
                  column | column-reverse;
}

Legt die MAIN-AXIS fest:

row (default)von links nach rechts
row-reversevon rechts nach links
columnvon oben nach unten
column-reversevon unten nach oben

Bei row | row-reverse verläuft die Main-Axis horizontal, bei column | column-reverse vertikal.

4 — Flex-Container: flex-wrap

flex-wrap CSS 
div {
  flex-wrap: nowrap | wrap | wrap-reverse;
}
nowrap (default)Alle Flex-Kinder in einer Zeile (möglicher Overflow).
wrapFlex-Kinder werden auf mehrere Zeilen umbrochen, von oben nach unten.
wrap-reverseFlex-Kinder werden auf mehrere Zeilen umbrochen, von unten nach oben.

flex-flow ist die Kurzschreibweise für beide: flex-flow: row nowrap; (default).

5 — Flex-Container: justify-content

justify-content CSS 
div {
  justify-content:
    flex-start | flex-end | center |
    space-between | space-around | space-evenly;
}

flex-start (default). Richtet die Flex-Kinder auf der MAIN-AXIS aus – bei row | row-reverse horizontal, bei column | column-reverse vertikal.

space-betweenErstes Kind am Anfang, letztes am Ende, der Rest gleichmäßig dazwischen.
space-aroundJedes Kind bekommt links und rechts gleich viel Platz (außen daher nur halb so viel wie zwischen den Kindern).
space-evenlyAlle Abstände – auch die äußeren – sind exakt gleich groß.

6 — Flex-Container: align-items & align-content

align-items CSS 
div {
  align-items:
    flex-start | flex-end | center |
    stretch | baseline;
}

stretch (default). Richtet die Flex-Kinder auf der CROSS-AXIS aus – bei row | row-reverse vertikal, bei column | column-reverse horizontal.

💡
Der Klassiker: perfekt zentrieren
display: flex; justify-content: center; align-items: center; zentriert ein Element horizontal und vertikal in seinem Container – früher eines der schwierigsten Probleme in CSS.

align-content

align-content CSS 
div {
  align-content:
    flex-start | flex-end | center |
    space-between | space-around;
}

flex-start (default). Richtet die Zeilen eines MULTI-LINE-Flex-Containers aus, also nur bei flex-wrap: wrap | wrap-reverse – nicht bei flex-wrap: nowrap.

ℹ
align-items vs. align-content
align-items verschiebt die Kinder innerhalb ihrer Zeile. align-content verschiebt die Zeilen als Ganzes im Container – deshalb hat es nur bei mehreren Zeilen eine Wirkung.

7 — Flex-Container: gap

gap CSS 
div {
  gap: 10px;        /* both */
  gap: 10px 20px;   /* row-gap column-gap */

  row-gap: 10px;
  column-gap: 20px;
}

Steuert explizit den Abstand zwischen den Flex-Kindern.

Dieser Abstand wird nur zwischen den Elementen angewendet, nicht an den Außenkanten.

8 — Flex-Kinder: order

Während die bisherigen Properties auf den Container gesetzt werden, stehen die folgenden Properties auf den einzelnen Kindern. Damit kann man jedes Kind individuell steuern.

order

order CSS 
div {
  order: number;
}

Standardmäßig werden die Flex-Elemente in der Reihenfolge des DOM-Baums angeordnet (alle haben order: 0).

order steuert die Reihenfolge, in der sie im Flex-Container erscheinen. Kleinere Werte kommen zuerst.

⚠
Nur visuell
order ändert nur die Darstellung. Screenreader und die Tab-Taste folgen weiterhin der Reihenfolge im HTML. Wichtige Inhalte sollten deshalb auch im HTML in einer sinnvollen Reihenfolge stehen.

9 — Flex-Kinder: flex-grow & flex-shrink

flex-grow CSS 
div {
  flex-grow: number;
}

flex-grow (default 0) definiert die Fähigkeit eines Flex-Kindes, bei Bedarf zu wachsen.

  • Sind alle Flex-Kinder auf 1 eingestellt, wird der verbleibende Platz im Container gleichmäßig auf alle Kinder verteilt.
  • Ist ein Flex-Kind auf 2 und die anderen auf 1 eingestellt, bekommt dieses Kind doppelt so viel vom verbleibenden Platz wie jedes der anderen.

flex-shrink

flex-shrink CSS 
div {
  flex-shrink: number;
}

flex-shrink (default 1) definiert die Fähigkeit eines Flex-Kindes, bei Bedarf zu schrumpfen – also wenn der Platz im Container nicht für alle reicht. Es funktioniert spiegelbildlich zu flex-grow: Ein Kind mit höherem Wert gibt mehr Platz ab. Mit flex-shrink: 0 schrumpft ein Kind gar nicht.

10 — Flex-Kinder: flex-basis

flex-basis CSS 
div {
  flex-basis: px | % | auto;
}

flex-basis ist die Wunschgröße eines Elements, bevor der verbleibende Platz verteilt wird. Es kann eine Länge (z. B. 100%, 0px) oder auto sein.

WertBedeutungSinnvoll mit
flex-basis: auto (default)„Ich möchte so groß wie mein Inhalt sein.“–
flex-basis: 0px„Ich möchte 0px groß sein.“flex-grow
flex-basis: 100%„Ich möchte so breit wie der Container sein.“flex-wrap: wrap → siehe Flexbox – Multiline

flex-basis: 0 vs. flex-basis: auto

flex-basis: 0

Der ganze Flex-Container (ALL SPACE) wird proportional zum flex-grow-Wert auf die Flex-Kinder verteilt. Der Inhalt spielt keine Rolle.

flex-basis: auto

Jedes Kind bekommt zuerst den Platz für seinen Inhalt. Nur der übrige Bereich (EXTRA SPACE) wird proportional zum flex-grow-Wert verteilt.

ℹ
Flex-Algorithmus

Zuerst Basis → dann shrink (falls zu wenig Platz) → dann grow (falls Platz übrig).

11 — Flex-Shorthand

In der Praxis schreibt man flex-grow, flex-shrink und flex-basis fast immer zusammen mit der Kurzform flex:

flex-Shorthand CSS 
/* Three values: flex-grow & flex-shrink & flex-basis */
flex: 0 0 100%;

/* One value, unitless number: flex-grow */
flex: 1;
/* → entspricht flex: 1 1 0; */

Typische Werte – und was sie „sagen“

WertBedeutungHinweis
flex: 0 1 auto (default) „I want to be the width of my real content … BUT if necessary I will shrink.“ Verhindert, dass die Zeile überläuft.
flex: 1 0 auto „I want to be the width of my real content … BUT if possible I will grow.“ Kann die Zeile überlaufen lassen (DANGEROUS!)
flex: 1 1 auto „I want to be the width of my real content … BUT let’s see if I have to grow or shrink.“ Flexibel in beide Richtungen.
flex: 0 0 auto „I will be the width of my real content … and nobody touches me!“ Kann die Zeile überlaufen lassen (DANGEROUS!)
flex: 1 0 0px
flex: 1		 „I will start with my absolute minimum size … BUT if possible I will grow.“ Auf alle Kinder gesetzt, werden alle gleich groß.
flex: 0 0 100% „I will take the entire flex-line for me.“ Sinnvoll mit flex-wrap: wrap.
ℹ
Präzisierung zu flex: 1

Laut Spezifikation steht flex: 1 für flex: 1 1 0 (mit flex-shrink: 1). Für das Ergebnis „alle gleich groß“ macht das keinen Unterschied, denn mit flex-basis: 0 muss ohnehin nichts schrumpfen.

12 — Pattern: Multiline-Layout (Mobile First)

Pattern: Ein komplettes Seitenlayout mit Header, Hauptinhalt, zwei Sidebars und Footer, das sich an die Bildschirmbreite anpasst. Wir beginnen mit dem Layout für Smartphones (Mobile First) und erweitern es für größere Bildschirme.

HTML HTML 
<div class="wrapper">
  <header class="header">Header</header>
  <article class="main">...</article>
  <aside class="aside aside-1">Aside 1</aside>
  <aside class="aside aside-2">Aside 2</aside>
  <footer class="footer">Footer</footer>
</div>

1) Flex-Container

Schritt 1 CSS 
.wrapper {
  display: flex;
  flex-direction: row;
  flex-wrap: wrap;
}

2) Flex-Kinder – Mobile First

Schritt 2 CSS 
/* Jedes Kind nimmt die ganze Zeile ein → alles untereinander */
.wrapper > * {
  flex: 0 0 100%;
}

3) Flex-Kinder – Tablet

Schritt 3 CSS 
@media all and (min-width: 600px) {
  /* Die beiden Asides teilen sich eine Zeile */
  .aside { flex: 1 0 0; }
}

4) Flex-Kinder – Desktop

Schritt 4 CSS 
@media all and (min-width: 800px) {
  .main { flex: 3 0 0; }
  .header { order: 1; }
  .aside-1 { order: 2; }
  .main { order: 3; }
  .aside-2 { order: 4; }
  .footer { order: 5; }
}
ℹ
@media

Die Regeln in @media all and (min-width: 600px) { … } gelten nur, wenn das Browserfenster mindestens 600px breit ist. Media Queries behandeln wir ausführlich in Lektion 2.7.

13 — Flexbox: Summary

Flex-Container

Flex-Container CSS 
display: flex | inline-flex;

flex-direction: row (default) | column | row-reverse | column-reverse;
flex-wrap: nowrap (default) | wrap | wrap-reverse;
flex-flow: row nowrap (default); /* Shorthand for flex-direction & flex-wrap */

justify-content: flex-start (default) | center | flex-end | space-around | space-between | space-evenly;
align-items: flex-start | center | flex-end | stretch (default) | baseline;
align-content: flex-start (default) | center | flex-end | stretch;
gap: 10px;

Flex-Kinder

Flex-Kinder CSS 
order: number;
flex-grow: number;
flex-shrink: number;
flex-basis: auto | px | %;
flex: 0 1 auto (default); /* Shorthand for flex-grow & flex-shrink & flex-basis */

Projektschritt

Projektschritt 2.5

Flexbox für Header, Navigation, Footer & Karten

Zuerst werden Header, Navigation und Footer zu Flex-Containern – die inline-block-Navigation aus 2.2 wird dadurch überflüssig. Danach steuern wir die Flex-Kinder: Text und Bild im HTML-Abschnitt teilen sich den Platz 2 : 1, die CSS-Karten brechen automatisch um, und mit order: -1 steht das Bild oben, obwohl es im HTML zuletzt kommt.

demoseite/css/style.css (neu in 2.5) CSS 
/* ---- 2.5 Flexbox: Container & Kinder --------------------- */

/* Marke links, Navigation rechts */
header {
  display: flex;
  justify-content: space-between;
  align-items: center;
  flex-wrap: wrap;
  gap: 1rem;
}

/* Navigation: Flexbox statt inline-block */
#nav-menu ul {
  display: flex;
  flex-wrap: wrap;
  gap: 1.5rem;
}

#nav-menu li {
  margin: 0;
}

/* Footer: Infos links, Links rechts */
.footer-info {
  display: flex;
  justify-content: space-between;
  align-items: flex-start;
  gap: 2rem;
  margin-top: 2rem;
}

/* -- Flex-Kinder: Text/Bild-Layout und Karten -- */

/* Text und Bild nebeneinander: Text bekommt doppelt so viel Platz */
.content-with-image {
  display: flex;
  align-items: center;
  gap: 2rem;
}

.text-content {
  flex: 2;
}

.content-with-image img {
  flex: 1;
  min-width: 0;
  max-width: 200px;
}

/* Karten in Reihen, die automatisch umbrechen */
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 1.5rem;
}

.card {
  flex: 1 1 250px;
  display: flex;
  flex-direction: column;
  overflow: hidden;
  border-radius: 10px;
  background: white;
}

.card img {
  order: -1;           /* Bild nach oben, obwohl es im HTML zuletzt steht */
  height: 150px;
  object-fit: cover;
}

.card h3,
.card p {
  margin: 1rem 1rem 0;
}

📁 Stand nach dieser Lektion: beispiele/2.5/

Häufige Fehler

Fehler: display: flex auf dem Kind statt auf dem Container

Die Elemente stehen weiterhin untereinander.

display: flex gehört auf das Eltern-Element – es wirkt nur auf dessen direkte Kinder.

Fehler: justify und align verwechselt

Mit flex-direction: column zentriert justify-content: center plötzlich vertikal.

justify = Main-Axis, align = Cross-Axis. Bei column drehen sich die Achsen.

Fehler: Gleich große Spalten werden ungleich

Mit flex-grow: 1 allein sind Spalten mit mehr Text breiter.

flex: 1 verwenden – das setzt zusätzlich flex-basis: 0, sodass der Inhalt keine Rolle spielt.

Aufgaben

Aufgabe 1 Flexbox Froggy

Spiele Flexbox Froggy bis Level 24. Notiere zu jedem Level die verwendete Property.

Aufgabe 2 Platz berechnen

Ein Container ist 900px breit. Drei Kinder haben flex: 1, flex: 2 und flex: 3. Wie breit wird jedes Kind? Was ändert sich, wenn ein Kind zusätzlich flex-basis: 300px hat?

Aufgabe 3 Text und Bild nebeneinander

Baue einen Artikel, in dem Text und Bild nebeneinander stehen und sich den Platz gleichmäßig teilen:

  • Packe das Bild in einen Wrapper (<div><img></div>). Als direktes Flex-Kind verhält sich ein Bild wegen seiner eigenen, natürlichen Größe oft unerwartet.
  • Gib dem Bild max-width: 100%; height: auto;, dem Artikel display: flex; align-items: center; und beiden Kindern flex: 1.
Bonus Sticky Footer

Sorge dafür, dass der Footer auch bei wenig Inhalt immer ganz unten im Fenster steht: body als Flex-Container mit flex-direction: column; min-height: 100vh; – welches Kind braucht flex: 1?
