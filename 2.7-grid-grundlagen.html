CSS Grid Grundlagen

CSS Grid ca. 90 min Layout

Lernziele

  • Die Grundbegriffe von CSS Grid kennen: Container, Items, Lines, Tracks, Areas
  • Spalten und Zeilen mit grid-template-columns/-rows, fr und repeat() definieren
  • Abstände und Ausrichtung im Grid steuern
  • Grid Items über Linien, span und benannte Bereiche (grid-template-areas) platzieren
  • Implizite Zeilen, minmax(), auto-fit und auto-fill einsetzen
  • Entscheiden, wann Grid und wann Flexbox das richtige Werkzeug ist

1 — Was ist CSS Grid?

CSS Grid ist ein zweidimensionales Layout-System für das Web – es kann Zeilen und Spalten gleichzeitig handhaben. Flexbox dagegen ordnet Elemente immer entlang einer Achse an.

Hauptkonzepte

Grid ContainerDas Elternelement mit display: grid
Grid ItemsDie direkten Kindelemente des Containers
Grid LinesDie Trennlinien zwischen den Tracks (nummeriert ab 1)
Grid TracksDie Zeilen und Spalten
Grid AreasBenannte Bereiche im Grid (können mehrere Zellen umfassen)

Grundlegendes Beispiel

Grid CSS 
.container {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
  grid-template-rows: 100px 200px;
  gap: 10px;
}

Resultat: 3 Spalten, 2 Zeilen mit Abstand. Die mittlere Spalte ist doppelt so breit wie die äußeren.

2 — Grid-Container-Eigenschaften I

Grid Container definieren

display: grid | inline-grid – aktiviert das Grid-Layout für das Element.

grid-template-columns und grid-template-rows

Spalten definieren CSS 
.grid {
  /* 3 gleiche Spalten */
  grid-template-columns: 1fr 1fr 1fr;
  /* oder kürzer: */
  grid-template-columns: repeat(3, 1fr);

  /* Verschiedene Größen */
  grid-template-columns: 200px 1fr 100px;

  /* Auto-Größe basierend auf Inhalt */
  grid-template-columns: auto 1fr auto;
}

Einheiten

fr (fraction)Teilt den verfügbaren Platz auf (nachdem feste Größen abgezogen wurden)
px, em, %Feste Größen
autoGröße basierend auf dem Inhalt
minmax()Flexible Bereiche zwischen einem Minimum und einem Maximum
ℹ
Beispiel zu fr

Bei grid-template-columns: 200px 1fr 100px in einem 900px breiten Container bekommt die mittlere Spalte 900 − 200 − 100 = 600px.

3 — Grid-Container-Eigenschaften II

Abstände: gap (früher grid-gap)

gap CSS 
.grid {
  gap: 20px;              /* Alle Abstände */
  gap: 10px 20px;         /* row-gap column-gap */
  row-gap: 10px;          /* Nur Zeilen */
  column-gap: 20px;       /* Nur Spalten */
}

Ausrichtung: justify-items & align-items

Richten die Items innerhalb ihrer Zelle aus:

justify-items / align-items CSS 
.grid {
  justify-items: start | center | end | stretch;  /* horizontal */
  align-items: start | center | end | stretch;    /* vertikal */
  place-items: center;                            /* Kurzform für beide */
}

Ausrichtung: justify-content & align-content

Richten das gesamte Grid im Container aus (wenn das Grid kleiner als der Container ist):

justify-content / align-content CSS 
.grid {
  justify-content: start | center | end | space-between | space-around;
  align-content: start | center | end | space-between | space-around;
}

4 — Grid Items positionieren

Mit Grid Lines (linienbasiert)

Die Linien eines Grids sind durchnummeriert: Bei 3 Spalten gibt es die vertikalen Linien 1, 2, 3 und 4. Ein Item wird platziert, indem man angibt, von welcher bis zu welcher Linie es reicht.

Grid Lines CSS 
.item {
  grid-column-start: 1;
  grid-column-end: 3;      /* Von Linie 1 bis 3 */

  /* oder kürzer: */
  grid-column: 1 / 3;      /* Spalten 1–2 */
  grid-row: 2 / 4;         /* Zeilen 2–3 */

  /* Span-Notation */
  grid-column: 1 / span 2; /* Start bei 1, erstreckt sich über 2 Spalten */
  grid-row: span 3;        /* Erstreckt sich über 3 Zeilen */
}

Kurzform

grid-area CSS 
.item {
  grid-area: 2 / 1 / 4 / 3;  /* row-start / col-start / row-end / col-end */
}

Beispiel-HTML

HTML HTML 
<div class="grid">
  <div class="item header">Header</div>
  <div class="item content">Content</div>
  <div class="item sidebar">Sidebar</div>
</div>

5 — Named Grid Areas

Benannte Grid-Bereiche machen Layouts lesbar und wartbar: Man „zeichnet“ das Layout direkt im CSS.

CSS CSS 
.grid {
  display: grid;
  grid-template-columns: 1fr 3fr 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header  header  header"
    "sidebar main    ads"
    "footer  footer  footer";
  gap: 20px;
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.ads     { grid-area: ads; }
.footer  { grid-area: footer; }
HTML HTML 
<div class="grid">
  <header class="header">Header</header>
  <aside class="sidebar">Sidebar</aside>
  <main class="main">Main Content</main>
  <aside class="ads">Advertisements</aside>
  <footer class="footer">Footer</footer>
</div>

Regeln für grid-template-areas

Jede Zeile in Anführungszeichen ist eine Grid-Zeile; jedes Wort eine Zelle. Ein Bereich muss ein Rechteck bilden. Ein Punkt (.) steht für eine leere Zelle.

6 — Grid vs. Flexbox

AspektFlexboxCSS Grid
Dimensionen1D (eine Richtung)2D (Zeilen + Spalten)
VerwendungKomponenten-LayoutSeiten-Layout
ContentContent-First (Inhalt bestimmt die Größe)Layout-First (Raster bestimmt die Größe)
AusrichtungEntlang einer AchseIn beide Richtungen

Flexbox verwenden für

  • Navigation bars
  • Button groups
  • Zentrieren von Elementen
  • Gleichmäßige Verteilung

Grid verwenden für

  • Seitenlayout (Header, Main, Footer)
  • Card grids
  • Dashboard layouts
  • Komplexe responsive Designs

Beide können kombiniert werden!

Kombination CSS 
.page-grid { display: grid; }   /* Seitenlayout */
.nav-flex { display: flex; }    /* Navigation innerhalb des Grids */

7 — Auto-Grid und minmax()

Automatische Grid-Erstellung: grid-auto-rows & grid-auto-columns

Gibt es mehr Items als definierte Zellen, legt der Browser automatisch neue (implizite) Zeilen an. Deren Höhe steuert grid-auto-rows:

grid-auto-rows CSS 
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows: 200px;  /* Neue Zeilen haben 200px Höhe */
}

minmax() für flexible Größen

minmax() CSS 
.grid {
  grid-template-columns: minmax(200px, 1fr) minmax(300px, 2fr);
  grid-auto-rows: minmax(100px, auto);
}

minmax(100px, auto) bedeutet: mindestens 100px hoch, bei mehr Inhalt aber so hoch wie nötig.

auto-fit und auto-fill

auto-fit / auto-fill CSS 
/* auto-fit: Spalten kollabieren, wenn sie leer sind */
.grid {
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
}

/* auto-fill: Spalten bleiben auch erhalten, wenn sie leer sind */
.grid {
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
}

Der Browser legt so viele Spalten an, wie mit mindestens 250px Platz haben. Der Unterschied zeigt sich nur bei wenigen Items: auto-fit streckt die vorhandenen Items über die ganze Breite, auto-fill lässt leere Spalten stehen.

Projektschritt 2.7

Seitenlayout mit Grid

Das Seitenlayout wird zum Grid: Alle Bereiche laufen über beide Spalten, nur der Abschnitt „HTML Elemente“ und die Sidebar stehen nebeneinander.

demoseite/css/style.css (neu in 2.7) CSS 
/* ---- 2.7 CSS Grid Grundlagen ------------------------------- */

/* Zwei Spalten: Inhalt + 300px Sidebar */
main {
  display: grid;
  grid-template-columns: 1fr 300px;
  column-gap: 2rem;
  align-items: start;
}

/* Überschrift und alle Sections über beide Spalten (Linie 1 bis -1) */
main > h1,
main > section {
  grid-column: 1 / -1;
}

/* Ausnahme: HTML-Elemente links, Sidebar rechts daneben */
#elemente {
  grid-column: 1;
}

main > aside {
  grid-column: 2;
  grid-row: 3;
}

Häufige Fehler

Fehler: Spalten zählen statt Linien

grid-column: 1 / 3 wird als „Spalte 1 bis 3“ verstanden – das Item ist aber nur 2 Spalten breit.

Die Zahlen bezeichnen Linien. Wer in Spalten denkt, nimmt grid-column: 1 / span 2.

Fehler: grid-template-areas ungültig

Ein Bereich bildet eine L-Form oder eine Zeile hat weniger Zellen als die anderen – das ganze Layout fällt in sich zusammen.

Jede Zeile braucht gleich viele Einträge, und jeder benannte Bereich muss ein Rechteck sein.

Fehler: grid-area-Name in Anführungszeichen

grid-area: "header"; wird ignoriert.

In grid-template-areas stehen die Zeilen in Anführungszeichen, beim Item aber der Name ohne: grid-area: header;
