Media Queries & responsive Grids

Lernziele

1 — Media Queries

Media Queries ermöglichen die Abfrage von Eigenschaften des Endgeräts – z. B. der Breite des Browserfensters. CSS-Regeln innerhalb einer Media Query gelten nur, wenn die Bedingung erfüllt ist.

Syntax CSS 
@media <media-type> and (<media-feature>) {
  /* styles */
}

Beispiel

Klassisch CSS 
@media screen and (min-width: 768px) { ... }

Moderner (Range-Syntax)

Range-Syntax CSS 
@media (600px <= width <= 1200px) { ... }
Media Typesscreen, print, all (veraltet: tty, tv, projection, braille, speech)
Media Featureswidth, height, orientation, prefers-color-scheme, pointer, hover, …
ℹ
min-width oder max-width?
  • Mobile First (empfohlen): Basis-CSS für kleine Bildschirme, dann mit min-width für größere erweitern (wie im Multiline-Beispiel aus Lektion 2.6 und bei Bootstrap).
  • Desktop First: Basis für große Bildschirme, dann mit max-width für kleinere vereinfachen (wie im Holy-Grail-Pattern unten).
⚠
Viewport-Meta-Tag nicht vergessen

Ohne <meta name="viewport" content="width=device-width, initial-scale=1.0"> im <head> tun Smartphones so, als wären sie ~980px breit – Media Queries greifen dann nicht wie erwartet.

2 — Responsive Grid Patterns I

Pattern 1: Responsive Card Grid

Card Grid CSS 
.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
  gap: 2rem;
}

Resultat: Die Cards brechen automatisch um, wenn der Platz nicht reicht!

Pattern 2: Holy Grail Layout

Der „Heilige Gral“ des Webdesigns: Header, drei Spalten (Sidebar, Inhalt, Werbung) und Footer – der Footer bleibt auch bei wenig Inhalt unten.

Holy Grail CSS 
.holy-grail {
  display: grid;
  min-height: 100vh;
  grid-template-columns: 200px 1fr 200px;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header header"
    "sidebar main ads"
    "footer footer footer";
}

@media (max-width: 768px) {
  .holy-grail {
    grid-template-columns: 1fr;
    grid-template-areas:
      "header"
      "main"
      "sidebar"
      "ads"
      "footer";
  }
}
💡
Die Stärke von grid-template-areas

Um das Layout für Smartphones umzubauen, muss man nur die „Zeichnung“ in grid-template-areas ändern – das HTML bleibt unverändert. Hier rutscht main mobil sogar vor die Sidebar.

3 — Responsive Grid Patterns II

Pattern 3: Dashboard Layout

Dashboard CSS 
.dashboard {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-auto-rows: minmax(200px, auto);
  gap: 1rem;
}

.widget-large {
  grid-column: span 2;
  grid-row: span 2;
}
.widget-wide {
  grid-column: span 2;
}
.widget-tall {
  grid-row: span 2;
}

@media (max-width: 1024px) {
  .dashboard {
    grid-template-columns: repeat(2, 1fr);
  }
  .widget-large { grid-column: span 1; }
}

Pattern 4: Magazine Layout

Magazine CSS 
.magazine {
  display: grid;
  grid-template-columns: repeat(6, 1fr);
  grid-auto-rows: 200px;
  gap: 1rem;
}

.article-featured { grid-column: span 4; grid-row: span 2; }
.article-large { grid-column: span 3; }
.article-small { grid-column: span 2; }

Ein 6-Spalten-Raster ist praktisch, weil es sich durch 2 und 3 teilen lässt: Artikel können halb (3), ein Drittel (2) oder zwei Drittel (4) der Breite einnehmen.

4 — Advanced Grid Features

Subgrid (CSS Grid Level 2)

subgrid CSS 
.main-grid {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
}

.nested-grid {
  display: grid;
  grid-template-columns: subgrid;  /* Erbt die Spalten vom Parent */
  grid-column: span 3;
}

Ein verschachteltes Grid hat normalerweise sein eigenes, unabhängiges Raster. Mit subgrid übernimmt es die Spuren des Eltern-Grids – so stehen z. B. Überschriften, Texte und Buttons in mehreren Karten exakt auf einer Linie.

Grid Functions

Grid Functions CSS 
.grid {
  /* fit-content: zwischen min-content und max-content, höchstens 300px */
  grid-template-columns: fit-content(300px) 1fr;

  /* repeat mit verschiedenen Patterns */
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

  /* min/max für responsive Designs */
  grid-template-rows: repeat(3, minmax(100px, max-content));
}

Dense Placement

Dense Placement CSS 
.masonry-style {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  grid-auto-flow: row dense;  /* Füllt Lücken automatisch */
}

Wenn große Items (mit span) nicht mehr in eine Zeile passen, entstehen Lücken. Mit dense füllt der Browser diese mit späteren, kleineren Items auf – die Reihenfolge auf dem Bildschirm entspricht dann aber nicht mehr der im HTML.

5 — Praktische Tipps & Best Practices

✓ DO

  • Verwende Grid für Layout, Flexbox für Komponenten
  • Nutze fr-Units für flexible Spalten
  • Verwende gap statt Margins für Abstände
  • Benenne Grid Areas für komplexe Layouts
  • Nutze auto-fit/auto-fill für responsive Designs

✗ DON’T

  • Überkomplizierte verschachtelte Grids
  • Jeden Container zu einem Grid machen
  • position: absolute innerhalb von Grids
  • Alte Browser ohne Fallbacks ignorieren

Debugging-Tipps

  • Der Firefox Grid Inspector zeigt die Grid Lines an.
  • Die Chrome DevTools visualisieren Grid Areas.
  • grid-template-areas macht den Code selbsterklärend.

Browser Support Check

@supports CSS 
@supports (display: grid) {
  .grid-layout { display: grid; }
}

@supports funktioniert wie eine Media Query, fragt aber ab, ob der Browser eine CSS-Eigenschaft unterstützt. Innerhalb steht das moderne Layout, außerhalb ein einfacher Fallback.

6 — Vollständiges Beispiel: Responsive Blog Layout

HTML HTML 
<div class="blog-layout">
  <header class="header">My Blog</header>
  <nav class="nav">Navigation</nav>
  <main class="content">
    <article>Article 1</article>
    <article>Article 2</article>
    <article>Article 3</article>
  </main>
  <aside class="sidebar">Sidebar</aside>
  <footer class="footer">Footer</footer>
</div>
CSS CSS 
.blog-layout {
  display: grid;
  min-height: 100vh;
  grid-template-columns: 200px 1fr 300px;
  grid-template-rows: auto auto 1fr auto;
  grid-template-areas:
    "header header header"
    "nav nav nav"
    "sidebar content sidebar-right"
    "footer footer footer";
  gap: 1rem;
}

.content {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
  gap: 2rem;
}
ℹ
Hinweis zum Beispiel

Damit die Bereiche wirklich an ihren Platz wandern, braucht jedes Kind noch seine grid-area-Zuordnung (.header { grid-area: header; } usw.). Der Bereich sidebar-right ist im HTML noch nicht belegt – hier könnte z. B. ein zweites <aside> stehen. Auch das .content-Element ist selbst wieder ein Grid: ein Grid im Grid.

Projektschritt

Projektschritt 2.8

Responsive mit Burger-Menü

Unter 800px Breite schalten wir das Grid ab und ersetzen die Navigation durch ein Burger-Menü ganz ohne JavaScript: Eine versteckte Checkbox merkt sich den Zustand, das zugehörige <label> ist das Icon.

demoseite/index.html (im header, vor nav) HTML 
<input type="checkbox" id="nav-toggle">
<label for="nav-toggle" aria-label="Menü öffnen">
  <span class="bar"></span>
  <span class="bar"></span>
  <span class="bar"></span>
</label>
demoseite/css/style.css (neu in 2.8) CSS 
/* ---- 2.8 Media Queries & responsive Grids ------------------ */

/* Burger-Menü: Checkbox ist unsichtbar, das Label ist das Icon */
#nav-toggle,
label[for="nav-toggle"] {
  display: none;
}

label[for="nav-toggle"] .bar {
  display: block;
  width: 25px;
  height: 3px;
  margin: 4px 0;
  background-color: white;
}

@media (max-width: 800px) {
  /* Grid aus: alles untereinander */
  main {
    display: block;
  }

  /* Burger anzeigen, Navigation zunächst verstecken */
  label[for="nav-toggle"] {
    display: block;
    cursor: pointer;
  }

  #nav-menu {
    display: none;
    width: 100%;
  }

  /* Checkbox angehakt → Navigation einblenden (~ = Geschwister-Kombinator) */
  #nav-toggle:checked ~ #nav-menu {
    display: block;
  }

  #nav-menu ul {
    flex-direction: column;
    gap: 0.5rem;
  }

  .content-with-image,
  .footer-info {
    flex-direction: column;
  }
}

/* Beim Drucken keine Navigation */
@media print {
  header,
  .back-to-top {
    display: none;
  }
}

Häufige Fehler

Fehler: Media Query wird nie aktiv

Die Regeln in @media (min-width: 900px) wirken nicht, obwohl das Fenster breit genug ist.

Prüfen, ob die Media Query nach den Basis-Regeln steht – bei gleicher Spezifität gewinnt die spätere Regel (Cascade!).

Fehler: Fehlender Viewport-Meta-Tag

Auf dem Smartphone wird die Desktop-Ansicht winzig verkleinert dargestellt.

<meta name="viewport" content="width=device-width, initial-scale=1.0"> in den <head> jeder Seite.

Fehler: span größer als die Spaltenanzahl

Ein Item mit grid-column: span 2 in einem einspaltigen Grid erzeugt eine zusätzliche implizite Spalte und horizontales Scrollen.

Das span in einer Media Query nur ab der Breite setzen, ab der es genügend Spalten gibt.

Aufgaben

Aufgabe 1 Holy Grail nachbauen

Baue das Holy-Grail-Layout nach, schreibe es aber Mobile First um (Basis einspaltig, ab 768px dreispaltig mit min-width).

Aufgabe 2 Dark Mode

Nutze das Media Feature prefers-color-scheme: dark, um der Demoseite einen dunklen Hintergrund und helle Schrift zu geben, wenn das Betriebssystem im Dark Mode ist.

Aufgabe 3 Magazin-Startseite

Gestalte die Karten der Demoseite im Magazine-Layout (6 Spalten): die erste Karte span 4 × span 2, die anderen span 2.

Bonus Subgrid für die Karten

Sorge mit grid-template-rows: subgrid dafür, dass in allen Karten einer Zeile Bild, Titel und Text exakt auf gleicher Höhe stehen – auch wenn die Texte unterschiedlich lang sind.
