Lektion 2.8 — Teil 2: CSS & Layout

Transformationen & Transitions

Animation ca. 45 min Grundlagen

Lernziele

  • Elemente mit transform verschieben, skalieren und drehen
  • Verstehen, dass transform nur die Darstellung ändert, nicht das Layout
  • Übergänge mit transition erstellen: Property, Dauer, Timing-Funktion, Verzögerung
  • Wissen, welche Properties sich animieren lassen und welche nicht
  • Hover-Effekte rücksichtsvoll einsetzen (prefers-reduced-motion)

1 — Transform

Mit transform wird ein Element verschoben, vergrößert/verkleinert oder gedreht – ohne dass sich die anderen Elemente bewegen.

Transform CSS 
/* Auf 80% verkleinern */
transform: scale(80%);

/* Element 10px nach rechts und 5px nach unten verschieben */
transform: translate(10px, 5px);

/* Um 15 Grad im Uhrzeigersinn drehen */
transform: rotate(15deg);

/* Mehrere Funktionen kombinieren (werden von links nach rechts angewendet) */
transform: translate(10px, 5px) rotate(15deg);
Live-Vorschau: drei Mal dieselbe Box, jeweils transformiert
translate
scale
rotate
ℹ
transform verändert das Layout nicht

Wie bei position: relative (Lektion 2.4) bleibt der ursprüngliche Platz des Elements reserviert. Die Nachbarn rücken nicht nach – das Element wird nur an anderer Stelle bzw. in anderer Größe gezeichnet.

transform-origin

Gedreht und skaliert wird standardmäßig um die Mitte des Elements. Mit transform-origin lässt sich der Bezugspunkt ändern:

transform-origin CSS 
transform-origin: center;      /* Default */
transform-origin: top left;    /* um die linke obere Ecke drehen */

2 — Transition

Ohne transition springt ein Element beim Hovern sofort in den neuen Zustand. Mit transition wird die Änderung über eine bestimmte Zeit sanft animiert.

Transition CSS 
/* Animiere ALLE CSS-Properties dieses Elements
   über 0.5s mit der ease-Timing-Funktion */
transition: all 0.5s ease;

/* Animiere nur die height-Property dieses Elements
   über 0.5s mit der ease-Timing-Funktion */
transition: height 0.5s ease;

/* Mehrere Properties mit eigener Dauer, durch Komma getrennt */
transition: transform 0.3s ease, background-color 0.5s linear;

Die Kurzschreibweise fasst vier Einzel-Properties zusammen:

PropertyBedeutungBeispiel
transition-propertyWelche Property wird animiert?background-color, all
transition-durationWie lange dauert der Übergang?0.3s, 300ms
transition-timing-functionWie verläuft die Geschwindigkeit?ease, linear, ease-in, ease-out, ease-in-out
transition-delayWartezeit vor dem Start0.2s

Mehr dazu: css-tricks.com/almanac/properties/t/transition/

💡
transition gehört auf das Element, nicht auf :hover

Steht transition auf dem Element selbst, wird die Änderung beim Hineinfahren und beim Verlassen animiert. Steht sie nur in der :hover-Regel, springt das Element beim Verlassen zurück.

3 — Was lässt sich animieren?

Animierbar sind Properties mit Zwischenwerten: Farben, Längen, Zahlen. Der Browser rechnet die Werte dazwischen aus.

animierbar

color, background-color, width, height, max-height, padding, margin, opacity, box-shadow, transform

nicht animierbar

display (zwischen block und none gibt es nichts dazwischen), font-family, position

Deshalb klappt man Menüs mit max-height und overflow: hidden auf (Variante 3 aus Lektion 2.1) statt mit display: none:

Aufklappen mit max-height CSS 
.submenu {
  max-height: 0;
  overflow: hidden;
  transition: max-height 0.5s ease;
}

nav li:hover .submenu {
  max-height: 300px;   /* größer als der Inhalt */
}
ℹ
Performance
transform und opacity kann der Browser besonders flüssig animieren, weil dabei kein neues Layout berechnet werden muss. Für Bewegungen also lieber transform: translate(…) statt top/left animieren.

4 — Bewegung reduzieren

Manche Menschen reagieren auf Animationen mit Schwindel oder Übelkeit und stellen im Betriebssystem „Bewegung reduzieren“ ein. Mit einer Media Query (Lektion 2.7) lässt sich das berücksichtigen:

prefers-reduced-motion CSS 
@media (prefers-reduced-motion: reduce) {
  * {
    transition: none;
  }
}

Projektschritt

Projektschritt 2.8

Sanfte Hover-Effekte

Zum Abschluss von Teil 2 bekommt die Demoseite Bewegung: Der Schatten der Abschnitte ändert sich sanft, die Karten heben sich beim Hovern an und der „Nach oben“-Button wird größer. Hänge den Abschnitt an style.css an.

demoseite/css/style.css (neu in 2.8) CSS 
/* ---- 2.8 Transformationen & Transitions -------------------- */

/* Der Schatten der Abschnitte (Hover aus 2.1) ändert sich jetzt sanft */
section {
  transition: box-shadow 0.5s ease;
}

/* Navigationslinks wechseln die Farbe weich */
#nav-menu a {
  transition: color 0.3s ease;
}

/* Karten heben sich beim Hover leicht an */
.card {
  transition: transform 0.3s ease, box-shadow 0.3s ease;
}

.card:hover {
  transform: translateY(-5px);
  box-shadow: 0 8px 20px rgba(0, 0, 0, 0.2);
}

/* "Nach oben"-Button wird beim Hover etwas größer */
.back-to-top a {
  transition: transform 0.3s ease, background-color 0.3s ease;
}

.back-to-top a:hover {
  transform: scale(1.1);
  background-color: #7f8c8d;
}

/* Wer im Betriebssystem "Bewegung reduzieren" eingestellt hat,
   bekommt keine Animationen */
@media (prefers-reduced-motion: reduce) {
  * {
    transition: none;
  }
}

📁 Stand nach dieser Lektion: beispiele/2.8/

Häufige Fehler

Fehler: transition nur in der :hover-Regel

Die Animation läuft beim Hineinfahren, beim Verlassen springt das Element aber sofort zurück.

transition auf das Element selbst schreiben, nicht in :hover.

Fehler: display animieren wollen

transition: display 0.5s; bewirkt nichts – das Element erscheint schlagartig.

Mit max-height, opacity oder transform arbeiten.

Fehler: Mehrere transform-Regeln überschreiben sich

transform: scale(1.1); in :hover hebt ein vorher gesetztes transform: rotate(5deg); auf.

Alle Funktionen in eine Deklaration schreiben: transform: rotate(5deg) scale(1.1);
