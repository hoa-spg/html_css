1 — Was ist Bootstrap?

Bootstrap – das beliebteste CSS-Framework. Bootstrap ist ein Open-Source-CSS-Framework für schnelle und responsive Webentwicklung. Statt jedes Layout und jeden Button selbst zu schreiben, verwendet man fertige CSS-Klassen.

Warum Bootstrap?

  • Schnelle Entwicklung: vorgefertigte Komponenten
  • Responsive Design: Mobile-First-Ansatz
  • Konsistenz: einheitliches Design-System
  • Große Community: viel Support und Dokumentation
  • Anpassbar: eigene Themes und Styles

Bootstrap-5-Features

  • Kein jQuery mehr benötigt
  • Flexbox-basiertes Grid-System
  • CSS Custom Properties (CSS-Variablen)
  • Verbesserte API
  • Kleinere Dateigröße

Setup

Bootstrap per CDN einbinden HTML 
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
ℹ
Wo kommt was hin?

Das Stylesheet (<link>) gehört in den <head>, das Script am besten ans Ende des <body>. Das JavaScript brauchst du nur für interaktive Komponenten (Dropdowns, Modals, Navbar-Toggler …) – siehe Lektion 3.2.

💡
Du kennst die Technik schon

Bootstrap ist „nur“ CSS. Alles, was es macht, beruht auf dem, was du in diesem Kurs gelernt hast: Flexbox, Media Queries, Box Model, Klassen-Selektoren. Schau dir in den Entwicklertools an, welche CSS-Regeln hinter einer Bootstrap-Klasse stecken!

2 — Das Bootstrap-Grid-System

Bootstrap verwendet ein flexibles 12-Spalten-Grid-System auf Basis von CSS Flexbox. Jede Zeile wird gedanklich in 12 gleich breite Spalten geteilt; jedes Element gibt an, wie viele davon es belegt.

Grid-Struktur

Container → Row → Col HTML 
<div class="container">           <!-- Container -->
  <div class="row">               <!-- Zeile -->
    <div class="col-md-4">        <!-- Spalte -->
      Content 1
    </div>
    <div class="col-md-8">        <!-- Spalte -->
      Content 2
    </div>
  </div>
</div>
Live-Vorschau: 4 + 8 = 12 Spalten
col-md-4
col-md-8

Container-Typen

.containerFeste maximale Breite (max-width), die sich an jedem Breakpoint ändert
.container-fluid100 % Breite auf allen Breakpoints
.container-{breakpoint}100 % breit bis zum angegebenen Breakpoint, danach wie .container

Spalten-Klassen

.colAlle Spalten gleich breit
.col-{number}Bestimmte Spaltenanzahl (1–12)
.col-{breakpoint}-{number}Responsive Spalten: gilt ab dem angegebenen Breakpoint

3 — Responsive Breakpoints

Bootstrap definiert Breakpoints für verschiedene Gerätegrößen (5 benannte plus die Basis „X-Small“):

BreakpointClass InfixDimensions
X-SmallNone<576px
Smallsm≥576px
Mediummd≥768px
Largelg≥992px
X-Largexl≥1200px
XX-Largexxl≥1400px

Responsive-Grid-Beispiel

Responsive Grid HTML 
<div class="row">
  <div class="col-12 col-md-6 col-lg-4">
    <!-- Mobile: 12 Spalten, Tablet: 6 Spalten, Desktop: 4 Spalten -->
    Content 1
  </div>
  <div class="col-12 col-md-6 col-lg-8">
    <!-- Mobile: 12 Spalten, Tablet: 6 Spalten, Desktop: 8 Spalten -->
    Content 2
  </div>
</div>
ℹ
Mobile-First-Ansatz

Styles gelten ab dem Breakpoint aufwärts! col-md-6 bedeutet „ab 768px: 6 Spalten“. Darunter gilt die nächstkleinere Angabe (hier col-12). Intern ist das genau eine Media Query mit min-width – wie in Lektion 2.7.

4 — Utility Classes

Bootstrap Utilities – schnelle Styles ohne eigenes CSS. Jede Utility-Klasse setzt genau eine (oder wenige) CSS-Eigenschaften.

Spacing (Margin & Padding)

Spacing HTML 
<!-- Syntax: {property}{sides}-{size} -->
<div class="m-3">Margin auf allen Seiten</div>
<div class="mt-4">Margin top</div>
<div class="px-2">Padding left und right</div>
<div class="mb-5">Margin bottom</div>
propertym = margin, p = padding
sidest top, b bottom, s start (links), e end (rechts), x links + rechts, y oben + unten, leer = alle Seiten
size0, 1 (0.25rem), 2 (0.5rem), 3 (1rem), 4 (1.5rem), 5 (3rem), auto

Display & Flex

Display & Flex HTML 
<div class="d-flex justify-content-center align-items-center">
  Zentrierter Content
</div>
<div class="d-none d-md-block">Versteckt auf Mobile</div>

d-none d-md-block heißt: standardmäßig display: none, ab md (768px) display: block.

Colors & Backgrounds

Colors & Backgrounds HTML 
<p class="text-primary">Primary Text</p>
<div class="bg-success text-white p-3">Success Background</div>

Typography

Typography HTML 
<h1 class="display-4">Large Headline</h1>
<p class="lead">Lead paragraph</p>
<small class="text-muted">Muted text</small>

Spacing Scale: 0, 1 (0.25rem), 2 (0.5rem), 3 (1rem), 4 (1.5rem), 5 (3rem)

Projektschritt 3.1

Die Demoseite mit Bootstrap

Wir bauen die Seite ein zweites Mal – als index-bootstrap.html und ohne eigenes CSS, nur mit Bootstrap-Grid und Utilities. So lassen sich beide Ansätze direkt vergleichen. Das Grid ersetzt unser grid-template-columns: 1fr 300px durch col-lg-8 + col-lg-4.

demoseite/index-bootstrap.html (Ausschnitt) HTML 
<main class="container my-5">
  <h1 class="display-5 text-center mb-5">Demoseite: Webdesign Grundkurs</h1>

  <!-- Inhalt + Sidebar: ab lg 8 + 4 von 12 Spalten -->
  <div class="row g-4 mb-4">
    <section id="elemente" class="col-lg-8">
      <div class="bg-white p-4 rounded shadow-sm h-100"> … Tabelle … </div>
    </section>
    <aside class="col-lg-4">
      <div class="bg-warning-subtle p-4 rounded h-100"> … VS Code … </div>
    </aside>
  </div>

  <!-- Karten: mobil 1, ab md 2, ab lg 3 nebeneinander -->
  <div class="row g-4">
    <div class="col-md-6 col-lg-4">
      <div class="bg-white p-3 rounded shadow-sm h-100"> … Boxmodell … </div>
    </div>
    …
  </div>
</main>

📁 Stand nach dieser Lektion: beispiele/3.1/

Häufige Fehler

Fehler: col ohne row

Spalten stehen untereinander statt nebeneinander, oder die Ränder passen nicht.

Spalten (.col-*) müssen immer direkte Kinder einer .row sein, und die .row sollte in einem .container liegen.

Fehler: Mehr als 12 Spalten pro Zeile

col-md-8 + col-md-6 = 14 – die zweite Spalte rutscht in die nächste Zeile.

Pro Breakpoint sollen sich die Spalten einer Zeile auf 12 summieren (Umbrüche sind erlaubt, aber dann bewusst).

Fehler: Breakpoint falsch herum gedacht

col-md-6 wird als „nur auf Tablets“ verstanden.

Bootstrap ist Mobile First: md gilt ab 768px aufwärts – also auch auf Desktop, solange kein lg/xl etwas anderes sagt.
