Bootstrap: Komponenten & Anpassung

Bootstrap ca. 90 min Framework

Lernziele

  • Eine responsive Navbar mit Toggler und Dropdown aufbauen
  • Cards, Forms, Buttons und Alerts einsetzen
  • Typische responsive Patterns umsetzen: Hero Section und Feature Cards
  • Interaktive JavaScript-Komponenten wie das Modal über data-bs-*-Attribute verwenden
  • Bootstrap mit CSS Custom Properties, SCSS-Variablen, eigenen Utilities und Icons anpassen
  • Best Practices für Performance und Barrierefreiheit kennen

1 — Komponenten: Navigation

Die Navbar ist eine responsive Navigationsleiste. Auf kleinen Bildschirmen klappt sie zu einem „Hamburger“-Menü zusammen.

Navbar – responsive Navigation HTML 
<nav class="navbar navbar-expand-lg navbar-dark bg-dark">
  <div class="container">
    <a class="navbar-brand" href="#">My Website</a>

    <!-- Toggler für Mobile -->
    <button class="navbar-toggler" type="button"
            data-bs-toggle="collapse" data-bs-target="#navbarNav">
      <span class="navbar-toggler-icon"></span>
    </button>

    <!-- Navigation Links -->
    <div class="collapse navbar-collapse" id="navbarNav">
      <ul class="navbar-nav ms-auto">
        <li class="nav-item">
          <a class="nav-link active" href="#">Home</a>
        </li>
        <li class="nav-item">
          <a class="nav-link" href="#">About</a>
        </li>
        <li class="nav-item dropdown">
          <a class="nav-link dropdown-toggle" href="#" data-bs-toggle="dropdown">
            Services
          </a>
          <ul class="dropdown-menu">
            <li><a class="dropdown-item" href="#">Web Design</a></li>
            <li><a class="dropdown-item" href="#">Development</a></li>
          </ul>
        </li>
      </ul>
    </div>
  </div>
</nav>
navbar-expand-lgAb lg (992px) ist das Menü ausgeklappt, darunter erscheint der Toggler.
navbar-dark bg-darkHelle Schrift auf dunklem Hintergrund.
data-bs-toggle="collapse"
data-bs-target="#navbarNav"		Ein Klick auf den Toggler klappt das Element mit id="navbarNav" auf und zu (braucht das Bootstrap-JavaScript).
ms-automargin-left: auto („margin start“) – schiebt die Links nach rechts.

2 — Komponenten: Cards

Cards sind vielseitige Content-Container für Text, Bilder, Links usw.

Basic Card

Basic Card HTML 
<div class="card" style="width: 18rem;">
  <img src="image.jpg" class="card-img-top" alt="...">
  <div class="card-body">
    <h5 class="card-title">Card title</h5>
    <p class="card-text">Quick example text to build on the card title.</p>
    <a href="#" class="btn btn-primary">Go somewhere</a>
  </div>
</div>

Card Grid Layout

Card Grid HTML 
<div class="row">
  <div class="col-md-4 mb-4">
    <div class="card h-100">
      <div class="card-body">
        <h5 class="card-title">Service 1</h5>
        <p class="card-text">Description...</p>
      </div>
    </div>
  </div>
  <div class="col-md-4 mb-4">
    <div class="card h-100">
      <div class="card-body">
        <h5 class="card-title">Service 2</h5>
        <p class="card-text">Description...</p>
      </div>
    </div>
  </div>
</div>

h-100 (height: 100%) sorgt dafür, dass alle Cards einer Zeile gleich hoch sind. Card-Varianten: .card-header, .card-footer, .text-center, .bg-primary

3 — Komponenten: Forms

Bootstrap bietet umfassende Form-Styles und Layout-Optionen.

Basic Form

Basic Form HTML 
<form>
  <div class="mb-3">
    <label for="email" class="form-label">Email address</label>
    <input type="email" class="form-control" id="email" required>
    <div class="form-text">We'll never share your email.</div>
  </div>

  <div class="mb-3">
    <label for="password" class="form-label">Password</label>
    <input type="password" class="form-control" id="password" required>
  </div>

  <div class="mb-3 form-check">
    <input type="checkbox" class="form-check-input" id="remember">
    <label class="form-check-label" for="remember">Remember me</label>
  </div>

  <button type="submit" class="btn btn-primary">Submit</button>
</form>

Input Groups

Input Group HTML 
<div class="input-group mb-3">
  <span class="input-group-text">@</span>
  <input type="text" class="form-control" placeholder="Username">
</div>

Form Validation: .is-valid, .is-invalid, .valid-feedback, .invalid-feedback

ℹ
Alles aus Lektion 1.5 gilt weiter

Bootstrap ändert nur das Aussehen. label for/id, name, required, Input-Typen usw. funktionieren genauso wie in reinem HTML.

Links, die wie Buttons aussehen

Alerts HTML

5 — Responsive Design Patterns

Pattern 1: Hero Section

Ein großer, auffälliger Einstiegsbereich ganz oben auf der Seite:

Hero Section HTML 
<div class="container-fluid bg-primary text-white py-5">
  <div class="container">
    <div class="row align-items-center">
      <div class="col-lg-6">
        <h1 class="display-4">Welcome</h1>
        <p class="lead">Your success starts here.</p>
        <a href="#" class="btn btn-light btn-lg">Get Started</a>
      </div>
      <div class="col-lg-6">
        <img src="hero.jpg" class="img-fluid">
      </div>
    </div>
  </div>
</div>

img-fluid entspricht max-width: 100%; height: auto; – dem „Responsive Media“-Muster aus Lektion 2.5.

Feature Cards HTML

g-4 setzt den Abstand („gutter“) zwischen den Spalten – vergleichbar mit gap.

6 — JavaScript-Komponenten

Interaktive Komponenten mit Bootstrap JS – gesteuert über data-bs-*-Attribute, ganz ohne eigenes JavaScript.

Modal Dialog

Modal HTML 
<!-- Button trigger -->
<button class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#myModal">
  Open Modal
</button>

<!-- Modal -->
<div class="modal fade" id="myModal">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">
        <h5 class="modal-title">Modal title</h5>
        <button type="button" class="btn-close" data-bs-dismiss="modal"></button>
      </div>
      <div class="modal-body">
        Modal content goes here...
      </div>
      <div class="modal-footer">
        <button type="button" class="btn btn-secondary" data-bs-dismiss="modal">
          Close
        </button>
        <button type="button" class="btn btn-primary">Save</button>
      </div>
    </div>
  </div>
</div>

Weitere JS-Komponenten

CarouselBildslider
CollapseAusklappbare Bereiche
TabsTab-Navigation
TooltipsHover-Informationen
PopoversClick-Informationen
⚠
Ohne bootstrap.bundle.min.js passiert nichts

Modal, Dropdown, Collapse & Co. brauchen das Bootstrap-Script. Fehlt es, sehen die Komponenten zwar richtig aus, reagieren aber nicht auf Klicks.

7 — Customization & Themes

1. CSS Custom Properties überschreiben

CSS-Variablen CSS 
:root {
  --bs-primary: #your-color;
  --bs-font-sans-serif: 'Your Font', sans-serif;
}

2. SCSS-Variablen (bei Sass-Kompilierung)

_custom.scss SCSS 
// _custom.scss
$primary: #your-brand-color;
$font-family-sans-serif: 'Your Font', sans-serif;

// Dann Bootstrap importieren
@import "bootstrap/scss/bootstrap";

3. Eigene Utility Classes

Eigene Utilities CSS 
.text-brand { color: #your-color; }
.bg-gradient-brand {
  background: linear-gradient(45deg, #color1, #color2);
}

4. Bootstrap Icons

Bootstrap Icons HTML 
<link href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.7.2/font/bootstrap-icons.css" rel="stylesheet">
<i class="bi bi-heart-fill text-danger"></i>
ℹ
Platzhalter ersetzen
#your-color, #color1 usw. sind Platzhalter – dort gehört ein echter Farbwert hin, z. B. #2d6a4f. Das eigene Stylesheet muss nach Bootstrap eingebunden werden, damit es gewinnt (Cascade: Source Order).

8 — Best Practices & Performance

Bootstrap effizient einsetzen:

✓ DO

  • Verwende das Grid-System für Layout
  • Nutze Utility Classes für kleine Anpassungen
  • Setze auf Mobile-First responsive Design
  • Verwende semantisches HTML mit Bootstrap-Klassen
  • Teste auf verschiedenen Geräten

✗ DON’T

  • Überschreibe nicht zu viele Bootstrap-Styles
  • Vergiss nicht die Accessibility
  • Lade keine unnötigen JS-Komponenten
  • Verwende keine veralteten Bootstrap-Versionen

Performance-Tipps

Einbinden HTML 
<!-- CSS im <head>: nur benötigte Komponenten laden -->
<link href="bootstrap.min.css" rel="stylesheet">

<!-- JavaScript vor dem Ende von <body> -->
<script src="bootstrap.bundle.min.js"></script>

Customization-Workflow

  1. Starte mit Standard-Bootstrap
  2. Definiere eigene Farben/Fonts
  3. Erweitere mit eigenem CSS
  4. Teste das responsive Verhalten
💡
Accessibility

Bootstrap ist auf WCAG-Konformität ausgelegt – achte trotzdem selbst auf alt-Attribute und ARIA-Labels (z. B. aria-label="Menü öffnen" beim Navbar-Toggler und aria-label="Schließen" bei btn-close).

Häufige Fehler

Fehler: Navbar-Toggler oder Modal reagieren nicht

Die Komponenten sehen richtig aus, aber ein Klick bewirkt nichts.

bootstrap.bundle.min.js einbinden und prüfen, ob data-bs-target="#…" exakt zur id des Ziel-Elements passt.

Fehler: Eigenes CSS wird von Bootstrap überschrieben

.btn { background: green; } hat keine Wirkung.

Das eigene Stylesheet nach Bootstrap einbinden – oder besser die CSS-Variablen (--bs-…) anpassen bzw. eigene Klassen verwenden.

Fehler: Alte Bootstrap-4-Klassen

Tutorials verwenden ml-auto, data-toggle oder form-group – in Bootstrap 5 passiert damit nichts.

Bootstrap 5 nutzt ms-auto/me-auto, data-bs-toggle und mb-3. Immer die Doku zur verwendeten Version lesen.
