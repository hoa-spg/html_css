Demoseite: Webdesign Grundkurs

HTML Grundlagen

HTML (HyperText Markup Language) entstand Anfang der 1990er-Jahre am CERN. Tim Berners-Lee definierte eine einfache Auszeichnungssprache, um Dokumente im neu entstehenden World Wide Web miteinander zu verlinken.

Heute steht HTML5 für modernes, semantisches HTML. Elemente wie header, nav, main, section, aside und footer beschreiben die Bedeutung von Inhalten statt nur deren Aussehen.

HTML Elemente

Ein Element besteht aus Start-Tag, Inhalt und End-Tag, z. B. <p>Text</p>. Leere Elemente wie <img> haben keinen Inhalt und kein End-Tag.

Wichtige HTML-Elemente
Element Erklärung
head Metadaten, Titel und Verweise auf Ressourcen
body Alle sichtbaren Inhalte der Seite
header, nav, main, footer Semantische Bereiche der Seite
a Hyperlink zu anderen Seiten oder Bereichen
img Bild (leeres Element)
form, label, input Formulareingaben

Visual Studio Code

VS Code ist ein kostenloser Editor und der Industriestandard für Webentwicklung. Empfohlene Extensions:

  • Live Server – lokaler Server mit automatischem Neuladen
  • W3C Validator – prüft HTML direkt im Editor

CSS

CSS (Cascading Style Sheets) beschreibt das Aussehen von HTML-Inhalten: Farben, Schriften, Abstände und Layouts.

Boxmodell

Content, Padding, Border und Margin bestimmen Größe und Abstände.

Selektoren

Typ-, Klassen-, ID- und Attribut-Selektoren sowie Spezifität.

Positioning

static, relative, absolute, fixed, sticky und z-index.

Flexbox

1D-Layout: Ausrichtung, Verteilung und flexible Größen.

Grid

2D-Layout: Spalten, Zeilen und responsive Raster.

Frameworks

Bootstrap und Tailwind: Komponenten vs. Utility-Klassen.
