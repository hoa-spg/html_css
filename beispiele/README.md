# Beispiele: Demoseite „Webdesign Grundkurs“

Für Teil 1 (HTML) gibt es ein Beispielprojekt: den fertigen HTML-Stand nach
Lektion 1.5. Ab Teil 2 enthält jeder Ordner den vollständigen Stand der
Demoseite **nach** der jeweiligen Lektion. Öffnen mit Live Server (`index.html`).

| Ordner | Neu in dieser Lektion |
|--------|-----------------------|
| `1.5`  | Teil 1 komplett: HTML5-Grundgerüst, semantische Struktur, Tabelle, Newsletter-Formular |
| `2.1`  | `css/style.css`: Schriften, Farben, Tabelle, Hover, `::before` |
| `2.2`  | Reset, Box Model (auch Tabelle), Display |
| `2.3`  | Zebrastreifen, Vererbung, Formular-Styling, Spezifität |
| `2.4`  | Sticky Header, fixierter „Nach oben“-Link |
| `2.5`  | Header, Navigation und Footer mit Flexbox |
| `2.6`  | Text/Bild-Layout und Karten mit Flex-Kindern |
| `2.7`  | Seitenlayout mit CSS Grid (Inhalt + Sidebar) |
| `2.8`  | Media Queries, Burger-Menü (nur CSS), Druckansicht |
| `2.9`  | Sanfte Hover-Effekte: Transitions, Karten und Button mit `transform` |
| `3.1`  | `index-bootstrap.html`: Grid und Utilities |
| `3.2`  | Bootstrap: Navbar, Cards, Formular, Alert |
| `3.3`  | `index-tailwind.html`: dieselbe Seite mit Tailwind |

Das CSS ist kumulativ: Jede Lektion hängt einen kommentierten Abschnitt an
`style.css` an.

Grundlage: `2526/css-examples/webdesign_css_6steps` (minimalistisch
reduziert; Animationen und Dark Mode – dort Version 5 und 6 – sind nicht
enthalten).
